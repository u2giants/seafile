Add a new NAS folder to sync

seaf-cli download / sync attach a new local folder to a library. In this deployment each folder is a read-only bind-mount baked into the container, so a new one can't be added to a running container from here — it needs a config change + redeploy:

Steps

  1. (If needed) create the target library above, or note an existing library's UUID.
  2. In synology-seaf-cli/docker-compose.yml, add a service block for the new library: bind-mount the NAS folder at /source:ro, set SEAF_LIBRARY=<uuid>, and add fresh -staging / -data volumes.
  3. Add the library to LIBRARIES in seafile-server/nas-settings/app.py so it appears in this panel.
  4. Commit, let CI publish the image, then redeploy the seaf-cli stack on the NAS (see synology-seaf-cli/README.md).
